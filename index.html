Resume Creator

Why I Built This

I built this project to solve the common pain points of resume writing: vague metrics, inconsistent formatting, and generic phrasing. While single-prompt AI tools often produce robotic results, I wanted to see if an agentic, self-correcting AI pipeline could iterate on a draft to generate a highly credible, ATS-compliant resume.

What It Does

Users input raw details through a form. A multi-agent pipeline generates a structured resume via Gemini AI, reviews it for unsupported claims and weak bullets, revises automatically if quality falls below threshold (up to 2x), generates 15 tailored interview questions, and saves full generation history per authenticated user.

Users can copy plain text, export a polished PDF, and browse past generations — all behind JWT-secured authentication.

Key Challenges Solved

  • Multi-agent orchestration — sequential LLM calls with retry/backoff logic
  • Database migration from H2 to PostgreSQL — debugged a subtle @Lob/OID JSON corruption issue
  • PDF rendering fidelity — fixed faint-text export bug from dark-theme CSS gradients in html2canvas
  • JWT-based stateless auth with per-user data isolation
  • Dockerized all three services into one orchestrated docker-compose stack

Tech Stack

Backend: Java 21, Spring Boot, Spring Data JPA/Hibernate, Spring Security, JWT, Maven, Gemini API
Database: PostgreSQL
Frontend: React, React Router, Axios, Vite
PDF Export: html2canvas, jsPDF
DevOps: Docker, Docker Compose, Nginx, WSL2

How to Use It

  1. Clone the repo
  2. Set up .env with GEMINI_API_KEY, DB_USERNAME, DB_PASSWORD
  3. Run docker compose up --build
  4. Visit localhost:5173, register, and start generating!

Future Additions

  • RAG-grounded resume content using curated keyword banks
  • Per-user API rate limiting (Bucket4j / Redis-backed)
  • JD-tailored resumes: Re-weight bullets to match a pasted job description

LightChat App

Why I Built This

I built LightChat to understand how real-time web applications work beyond normal request-and-response websites. It explores how multiple browser users can connect to one server, join a shared chat session, send messages instantly, and receive live notifications when users enter or leave.

What It Does

Users open the chat page, enter a name, and join a shared real-time chat session. The app connects each browser to a Socket.IO server, announces joins, broadcasts messages instantly, shows disconnect notifications, plays a sound on new messages, and dynamically updates the chat UI without refreshing the page.

Key Challenges Solved

  • Real-time communication using Socket.IO events for instant messaging and status updates
  • Connection management — tracked and removed users via Socket IDs on disconnect
  • Event-based architecture separating join, send, receive, leave, and disconnect events
  • Dynamic DOM manipulation to create and position chat messages in real time
  • Configured Socket.IO CORS for local Live Server frontend at 127.0.0.1:5500
  • Added message sounds and join/leave notifications for a more interactive feel

Tech Stack

Frontend: HTML5, CSS3, Vanilla JavaScript
Backend: Node.js
Real-time communication: Socket.IO
Development server: VS Code Live Server
Package management: npm

How to Use It

  1. Clone: git clone https://github.com/killerop4689/lightchat-app.git
  2. cd lightchat-app/nodeserver
  3. npm install
  4. node index.js
  5. Open index.html via VS Code Live Server
  6. Visit 127.0.0.1:5500, enter a name, open another tab to test live messaging

Future Additions

  • Chat rooms for private group sessions
  • Message history stored in a database
  • Authentication with signup/login and user profiles
  • Online user list display
  • Improved mobile responsiveness
  • Full deployment for cross-network chatting
